# Pritam & Dipika — Unique Wedding Website

A romantic, modern editorial design (not Bengali-themed) with three pages:
1. Welcome page with a couple photo background
2. Live days/hours/minutes/seconds countdown
3. Venue details and a direct Google Maps link

## Add photos
- Put your couple background photo at `images/couple.jpg`
- Optional: put a venue photo at `images/venue.jpg`

## Update details
In `index.html`, edit the `WEDDING` object near the bottom:
- `dateISO` (India time example: `2026-11-25T19:00:00+05:30`)
- `dateDisplay`
- `timeDisplay`
- `venueName`
- `venueAddress`
- `mapSearch`

The current date/time/venue are starter values and should be confirmed before sharing.

## Deploy
Upload `index.html`, `README.md`, and the `images` folder to a GitHub repository. Import that repository in Vercel and deploy with no build command required.
